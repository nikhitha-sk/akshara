# Labeling style guide (v0.1)

Everyone who types or checks data follows these rules, so the data is consistent.

1. **Script:** Tulu is written in Kannada script (ಕನ್ನಡ ಲಿಪಿ). Tigalari comes later.
2. **Unicode:** always NFC. No zero-width characters (the scripts remove them automatically).
3. **Spell as people say it.** Write the Tulu word the way it is pronounced in your area; note the town in your profile. Don't "Kannada-ize" Tulu words.
4. **English words inside Tulu:** write them in Kannada script as pronounced (ಬಸ್, ಫೋನ್), not in English letters.
5. **Numbers:** write digits as said aloud in speech transcripts ("ಮೂಜಿ", not "3"); keep digits in typed text.
6. **Punctuation:** keep `. , ? !` Normal ASCII punctuation only.
7. **Romanized (WhatsApp) spellings:** type exactly how you would on your phone — no "correct" romanization. Several spellings of the same word are good.
8. **Speech:** the transcript must match what was *actually said*. If the speaker changed a word, fix the text, don't keep the prompt.
9. **When unsure,** add a `?` in the notes column instead of guessing.
